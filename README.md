# Хувийн санхүүгийн апп

Streamlit + SQLite дээр бүтсэн хувийн санхүүгийн апп.

## Ажиллуулах
    pip install -r requirements.txt
    python -m streamlit run app.py

## Функцууд
1. **Хуулга импорт** – CSV / Excel / PDF. Дараагийн хугацааны хуулга өмнөх өгөгдөл дээр нэмэгдэж, давхардсан гүйлгээг алгасна.
2. **Төсөв** – дараа сарын төсөв (сүүлийн 3 сарын дунджаас), ангилалаар төсөв vs гүйцэтгэл.
3. **Урт хугацааны зорилго** – байр, машин зэрэг. Урьдчилгаа, өөрийн хуримтлал, бусад эх үүсвэр, банкны зээлийг хосолж тооцно. Сарын хуримтлал нь төсвийн үлдэгдэлд автоматаар холбогдоно.

Туршихад зориулсан жишээ хуулга `sample_data/` хавтсанд байна.
